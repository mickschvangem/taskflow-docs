# Archive and restore projects

Archive projects that you no longer need to work on without permanently deleting their contents. Archived projects retain their tasks, comments, attachments, and other project information, but cannot be edited while archived.

Project archiving is currently available on the desktop/web version of TaskFlow. Only project owners and admins can archive or restore projects.

## Archive a project

1. Open the project you want to archive.
2. Click the three-dot menu in the upper-right corner.
3. Select **Archive project**.
4. In the confirmation window, click **Archive**.

The project is removed from your normal Projects list. Its contents are not deleted.

## Find an archived project

1. Go to **Projects**.
2. Change the **Status** filter to **Archived**.
3. Open the project you want to view.

Archived projects are read-only and cannot be edited until they are restored.

## Restore a project

1. Go to **Projects** and set the **Status** filter to **Archived**.
2. Open the project you want to restore.
3. Click the three-dot menu in the upper-right corner.
4. Select **Restore project**.

The restored project will appear in your normal Projects list again and can be edited.

## Permanently delete an archived project

You can permanently delete an archived project from its three-dot menu.

**Warning:** Permanently deleting a project cannot be undone. If you may need the project or its contents again, leave it archived instead.
